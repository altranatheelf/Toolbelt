Mishear plays your audio to speech-recognition models under bad listening conditions and keeps what they heard. The models and ffmpeg run in a small local engine, on this computer only, at 127.0.0.1:8766. This page is the controls. Nothing is hosted and nothing leaves the machine.

  1. Once: brew install ffmpeg python@3.12, then in the Toolbelt checkout cd modules/mishear && python3.12 -m venv .venv && . .venv/bin/activate && pip install -e .
  2. Each session: mishear serve (keep that terminal open). The first listen downloads the models once into ~/.cache; after that it is offline.
  3. On a phone, this module can't run the engine. Use it on the computer.
